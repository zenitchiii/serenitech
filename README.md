# SereniTech

> **An AI Companion For Every Student**  
> *Balance, Focus, Guided by Care*  
> **Your AI companion for calm, clarity, and emotional wellness.**

---

SereniTech is an AI-powered student wellness companion designed to support emotional well-being, foster deep academic focus, and bring calm to demanding routines. By combining real-time AI voice/text interaction with personalized guidance, SereniTech empowers students to balance productivity with mental health.

---

## ✨ Key Features

- 🧘 **Calm & Focus Companion:** Real-time AI assistant for instant emotional support, mindfulness check-ins, and focus coaching.
- 🔒 **Seamless Authentication:** Secure user sign-in and session management powered by Clerk.
- ⚡ **Real-Time Data Sync:** Serverless backend database powered by Convex for seamless state management and activity tracking.
- 🎙️ **Voice AI Integration:** Conversational assistant infrastructure powered by Vapi.
- 🎨 **Modern & Accessible UI:** Responsive interfaces designed with Tailwind CSS and Shadcn UI.
- 🌊 **Fluid Visuals & Motion:** Declarative micro-interactions and page transitions built with Framer Motion.
- 🔔 **Reliable Event Delivery:** Webhook management and event orchestration using Svix.

---

## 🛠️ Tech Stack

### Core Stack
* **[Vite](https://vitejs.dev/)** – Next-generation, fast build tool and development server.
* **[React.js](https://react.dev/)** – JavaScript library for building user interfaces.
* **[Next.js](https://nextjs.org/)** – React framework for full-stack application routing and features.
* **[Tailwind CSS](https://tailwindcss.com/)** – Utility-first CSS framework for rapid UI development.

### Libraries & Infrastructure
* **[Shadcn UI](https://ui.shadcn.com/)** – Reusable and customizable component library.
* **[Clerk](https://clerk.com/)** – Complete user management and authentication suite.
* **[Vapi](https://vapi.ai/)** – Voice AI assistant framework for real-time speech interaction.
* **[Convex](https://www.convex.dev/)** – Reactive, serverless database built for modern web apps.
* **[Svix](https://www.svix.com/)** – Enterprise-grade webhook dispatch system.
* **[Lucide Icons](https://lucide.dev/)** – Clean, modern icon set for React apps.
* **[Framer Motion](https://www.framer.com/motion/)** – Animation engine for intuitive user interfaces.
